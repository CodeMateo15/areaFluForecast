## Context

You want a separate, pip-installable package. A health department would give it
weekly area-level flu rates and area boundaries, and get 1–4 week forecasts from
the three strongest models:
- the graph model (`gnn_st`)
- a tuned LSTM
- a tuned Cola-GNN

Every forecast would be checked against "next week looks like this week"
(persistence) on the department's own data.

**How it helps the paper.** It turns Claims 3–4 ("ports by data alone",
"transfers across cities") into something a reader can run. It also covers AJE's
required code availability statement with a citable piece of software. It does
not change the evidence: the paper still reports the frozen backtest from the
tagged research repo, and the package is cited as software.

**Decisions made:** full package, built now, in a new separate repo. Claude
writes the code, so coding time is not the limit. What is: cluster runs
(parity and pretrained weights take hours plus queue time), your review of the
parity results, and the outside approvals (CPH terms, naming, publishing). So
the phases below are ordered by **gates**, not days. A phase starts only when
the gate before it passes. The Oct 14 draft still takes priority for your time.

## What the package does (user-facing API)

Working name: `areaflu`. Rename freely. It lives at `~/Developer/areaFlu`.

```python
import areaflu as af
city = af.City.from_files(
    rates="rates.csv",          # week, area, rate_per_100k (long) or wide
    areas="areas.geojson",      # boundary polygons; id column matches `area`
    id_col="area", flu_months=(10,11,12,1,2,3),
    anchors=None,               # optional: extra areas/edges not scored
)
city.fetch_weather()            # optional, Open-Meteo, no API key
bt = af.backtest(city, models=["gnn_st","lstm","colagnn"], seasons=2)
bt.report()                     # error relative to persistence, week-level tests
fc = af.forecast(city, horizons=(1,2,3,4))   # 23 FluSight quantiles per area
fc.to_csv("forecast.csv"); fc.plot()
```

The command line mirrors this: `areaflu check | backtest | forecast | tune`.

- **Built-in trust check.** `forecast()` looks up the latest backtest. It warns
  when no backtest exists, or when a model did not beat persistence there. This
  is the "build the check in" limit from PAPER_PLAN.
- **Pretrained weights.** `af.pretrained("boston")` gives a warm start or a
  no-local-training model for departments with short histories. It must pass the
  same trust check before it is used.

## Architecture: copy the research code in, don't depend on it

The research repo imports Boston at import time and hardcodes dates and paths,
so the package gets its own cleaned copies of the modules.

| Package module | Taken from | Changes |
|---|---|---|
| `city.py` | `Code/influenza/cities/__init__.py` `City` | Add `City.from_files`. Anchors and background become truly optional. No static registry. |
| `adjacency.py` | `Code/scrapers/derive_{columbus,amba,boston}_adjacency.py` | One `adjacency_from_polygons(features, id_of, precision=6, min_shared=2)`, plus an isolated-node check and an optional shapely `touches` mode for messy boundaries. |
| `data.py` | loader duck-type from `samples.load_dataset` (`Code/influenza/samples.py:327`) | One generic loader that reads the user's frames. Weather from Open-Meteo (`Code/scrapers/scrape_weather.py`). Demographics optional. |
| `windows.py`, `samples.py`, `climatology.py` | same names in `Code/influenza/` | Dates come from the city (no `POST_COVID_START` or fixed test window). **New:** a forecast origin at the last observed week with no target. |
| `models.py` | `SpatioTemporalGNN` (`models.py:328`), `MultivariateLSTM` (`run_lstm.py:63`), `ColaGNN` (`run_colagnn.py`) | LSTM and Cola-GNN move from scripts into the library. |
| `training.py` | `train_stgnn`, `mc_dropout_stgnn`, `calibrate_intervals` (`training.py:230,380,496`) and the LSTM `train_model` | Keep the four progress-line markers from CLAUDE.md. |
| `intervals.py`, `scoring.py` | copied almost as-is | None needed: they only use numpy and scipy. |
| `tune.py` | `Code/tune.py:53-81` search spaces, K=12, validation-only | Same equal budget for all three models, as in the paper. |
| `baselines.py` | `seasonal_prediction` (`run_seasonal_naive.py:48`) | Persistence and seasonal naive. |
| `checkpoint.py` | the `run_gnn.py:398` save format | Save the full ensemble, normalisation, climatology and interval fit, so a saved model forecasts without retraining. |

**Default model settings follow the ablations, not the Boston-specific setup.**
- Demographics are off by default. The ablations found them inside noise at 1–2
  weeks and harmful at 4 weeks.
- Anchors are off unless the department supplies them. The background node
  added +0.005.
- `gnn_st_paper` reproduces the paper's exact setup for anyone who has the same
  inputs.
- The adaptive adjacency uses `noadapt` for transfer, because its size is tied
  to the number of areas.

**Dependencies:** torch and torch-geometric (only `GCNConv`), numpy, pandas,
scipy, requests. Plots are an optional `[plot]` extra, with matplotlib.
Codecarbon, git and statsmodels are dropped.

**Sample data:** a small aggregated Boston (BPHC public dashboard) weekly panel
plus the Boston boundary GeoJSON, with the Open-Meteo attribution. No Columbus
data.

## Verification

  `columbus_area_edges.csv` and `amba_partido_edges.csv` from the same GeoJSON.
  Also tests for `City.from_files` validation, and a quantile and WIS round-trip
  against `Code/influenza/scoring.py` on fixed arrays.

  1 seed runs `check → backtest → forecast` end to end. It must write 23
  quantiles × areas × horizons, and the forecast dates must fall after the last
  observed week.
- **Parity (Explorer):** package WIS against the frozen backtest, per season and
  horizon, compared with `Code/compare_significance.py`. It should be tied at
  the week level.
- **Fresh install:** `pip install .` in a clean venv, then the README quickstart
  runs as written.
